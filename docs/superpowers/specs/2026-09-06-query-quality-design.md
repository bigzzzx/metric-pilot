# 问数质量与统一图执行

用户已确认先评测、统一图执行、再补充口径和示例复用，不要求真实数据源。

## 实施范围

- 独立 SQLite 评测数据，覆盖退款、空值、跨月和一对多关联；不修改运行中的 demo.db。
- 可重复的结果比较和 JSON 报告；离线验证与真实模型评测分开统计，不能把模拟输出视为模型准确率。
- 流式与非流式使用同一编译图、节点和条件边。图 custom 事件承载状态和 token；API 的 delta/approval_required/permission_denied/done 格式保持兼容。
- 状态、图装配、事件传输独立模块。最终回答的流式文本与非流式结构化输出保留各自协议。
- 发布指标从目录源读取，计划引用指标 ID 和定义指纹；执行前核对指纹，定义变化或未知引用停止执行并要求重新规划。
- SQL 示例只接受人工登记的验证记录，关联目录文档内容指纹；检索时再次检查权限和指纹，最多注入三个。自动执行成功不等于业务验证通过。

## 验证

覆盖两入口路由一致性、真实 token 事件、查询/修复/澄清、旧结果污染、权限和审批事件；验证指标变化、示例过期及权限过滤。保存离线评测报告，提供可选真实模型模式记录端到端首 token 与耗时。

## 边界

这版不是任意 SQL 的语义等价证明，不新增真实数据库或跨源查询，不执行任何业务写操作。指标引用核对是确定性校验，公式遵守情况仍需业务结果评测。
