# 浅色 Data Agent 控制台重设计

## 目标

将现有单页深色聊天页升级为一个浅色、紧凑、适合日常使用的 Data Agent 控制台。视觉层级参考现代 AI 工作区的克制布局：侧栏导航、居中的对话工作区、按需出现的上下文面板。只借鉴信息架构与交互密度，不复制 Yuxi、ChatGPT 或其他产品的品牌、素材与代码。

## 信息架构

桌面端采用三栏布局：

- 左栏（固定窄宽度）：产品名、工作区导航、离线服务状态。入口包括对话工作台、数据目录、任务运行与查询历史。
- 中栏（可伸缩）：当前工作区内容。对话工作台保留输入、回答、SQL、表格和 Job 状态；数据目录呈现现有 `catalog.json` 的表、字段、关联关系；任务运行展示当前会话启动的 Job。
- 右栏（固定窄宽度）：当前请求的执行轨迹。无活动请求时显示简短引导；有请求时以低对比步骤呈现意图、目录命中、SQL 审核及执行结果。

移动端隐藏左右栏；当前回答中仍可展开执行详情与 Catalog 命中，保证核心解释性不丢失。

## 视觉语言

- 白色主画布、极浅灰侧栏和细灰色分隔线；不使用深色背景或大面积渐变。
- 正文字号为 13px，辅助文字为 11–12px，页面/工作区名称为 14px；不使用营销式大 Hero 标题。
- 仅使用低饱和蓝作为链接、焦点和轻量交互强调色；成功状态使用低对比浅绿标签。
- 采用 6–12px 圆角、轻微阴影和更多空白，不让卡片、标签或工具轨迹压过主回答。

## 交互与状态

- 左栏入口只切换前端工作区，不改变后端 API。
- 对话工作区复用 `/api/chat`，并把返回的步骤同步到右栏；SQL 与表格保留在回答内，以折叠详情展示。
- 数据目录复用 `/api/catalog/search`，默认呈现全部静态目录条目；点击表后显示字段和关联关系。
- 任务运行复用 `/api/jobs/{run_id}` 的既有轮询结果，展示 Job 状态与日志。
- 查询历史只保存在当前浏览器内存；刷新页面即清空。
- 请求失败时，在对话内展示简洁错误说明，右栏不显示误导性的成功状态。

## 技术边界与验证

修改仅限 `src/main.jsx`、`src/styles.css` 及必要的前端辅助数据；Node Agent 与 API 契约不变。使用 React 状态管理当前工作区、会话消息、目录数据与任务状态。

验证方式：执行 `npm test` 保证 Agent 行为未回归，执行 `npm run build` 保证前端构建成功，并启动本地服务检查对话、目录、Job 状态与移动端布局。
