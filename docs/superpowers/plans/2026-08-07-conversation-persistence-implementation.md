# Data Agent 会话持久化实施计划

1. 在独立 `backend/conversations.py` 中实现版本化表结构、旧 `sessions` 安全迁移、用户归属校验、会话摘要与完整消息读写。
2. 先补充持久化服务测试，覆盖迁移幂等、用户隔离、排序、完整 payload 往返和 `client_message_id` 去重。
3. 在 FastAPI 中增加创建、列出、读取会话接口；改造普通与流式聊天接口，在成功和模型错误时写入完整终态。
4. 将 LangGraph 历史上下文改为从新的消息模型构造，明确过滤 UI 错误消息并把可信工具结果作为内部上下文传入。
5. 改造 React `Workspace`：登录后加载会话摘要，按需加载消息，服务端创建新会话，刷新后恢复最近会话，登出时清空内存状态。
6. 增加加载失败与发送失败状态，确保错误消息可恢复、同一次发送重试不重复。
7. 执行 Python 测试、前端构建和浏览器回归；验证刷新、后端重启、历史切换、用户隔离和继续聊天。
