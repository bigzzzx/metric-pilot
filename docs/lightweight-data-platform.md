# Metric Pilot 轻量数据中台实施方案

目标：将现有治理优先的 Data Agent 演进为“统一治理与数据服务底座 + Agent 智能入口”。本轮交付一个可运行、可验收的最小闭环。

## 1. 统一指标服务

- 增加已授权指标服务目录，以及 `POST /api/data-services/metrics/query`。
- 显式绑定 `metric_id + version`，使用结构化日期、维度、筛选条件；直接调用不需要模型。
- 复用已认证指标契约、Schema 校验、底层只读执行器和权限，Agent 使用相同编译入口。
- 返回结果、单位（未维护则留空）、指标版本、时间字段、数据更新时间及质量状态；未知新鲜度明确标记。
- 查询保存最小审计记录；不把结果明细重复长期保存。
- 提供前端试查入口与请求示例，已有会话认证同样适用于接口。

## 2. 一条真实执行的数据生产链路

- 登记固定的“已支付订单按日汇总”任务；字段映射来自已发布且有权限的订单资产。
- 任务按半开日期区间重算，每天输出日期、已支付金额、订单数及更新时间。
- SQLite 支持本地演示数仓；PostgreSQL 使用服务端单独配置的写入凭据，绝不提升现有只读账号权限。
- 仅允许固定 SQL 模板及专用 `mp_` 前缀目标表；不执行模型生成的任意 ETL 代码。
- 复用 `etl.execute` 权限与逐次 Human-in-the-loop 审批。审批绑定任务版本和参数，执行前复查权限、字段和数据源。
- 同一请求键幂等；同一目标任务并发互斥；日期区间重跑不重复累计。
- 数据变更与质量检查处于同一事务，检查失败回滚。持久化运行和步骤记录，失败后可显式重新申请审批重试。
- 首次产物进入目录草稿，沿用现有审核发布流程；每日运行只更新数据，不自动变更已审核指标定义。

## 3. 运行、血缘和复用

- 提供任务登记、发起运行、审批、运行详情和步骤结果的前端页面。
- 成功运行产生实际“源表 → 任务 → 汇总表”血缘；保留执行 SQL、参数、时间和运行 ID。
- 更新资产数据时间/数据版本，使现有 Redis 工具和完整回答缓存失效。
- 提供外部调度接入示例：通过现有认证请求运行，仍需逐次审批；后台 DAG 负责计划/等待/监控，不绕过审批。部署调度器及无人值守授权属于后续独立部署配置。
- 平台管理员可以代审外部生产服务发起的任务；执行仍使用申请人权限，并分别记录申请人与批准人。此能力不扩展到个人 SQL/MCP 审批。

## 验收

1. 同一指标与参数在 Agent 和数据服务 API 得到相同 SQL 与结果，明确 API 查询不调用模型。
2. 错误版本、未认证指标、未发布资产、停用数据源、未授权字段均在执行前被拒绝。
3. 未批准、拒绝、过期及参数被改动的 ETL 请求不能写入；无权限时返回缺少的具体权限。
4. 在隔离合成数仓实际执行日汇总，验证金额/订单数、区间重跑、幂等、质量失败回滚和真实血缘。
5. 记录指标 API 不含模型的耗时；分别报告本地验证与真实 PostgreSQL 验证，不混淆合成数据与真实业务数据。
6. 后台回归、前端测试与构建通过；提交代码和实际验收报告。

## 本轮边界

复用现有 FastAPI、SQLite 平台库、PostgreSQL、SQLGlot、工具注册/审批和目录审核。不自建通用 ETL IDE、调度器、CDC 引擎或逐表质量规则平台。原有只读问数路径保持兼容。

## 如何使用

1. 重启后端加载新路由和幂等迁移。数据服务与数据生产两个入口位于“数据目录”。
2. 数据服务：选择已认证指标及起止日期，按需要选择维度。版本由服务目录提供；版本不一致返回 409，重新确认口径后再请求。
3. 数据生产：管理员展开“登记日汇总任务”，选择已发布的订单明细表，核对订单日期、金额、状态、唯一标识及 PAID 的真实枚举值。生产模板只统计已支付订单，不自动套用到支付流水或订单明细项表。
4. SQLite 演示任务无需新的凭据。PostgreSQL 任务填写目标 Schema（须已存在）和服务端写入 DSN 的环境变量名，例如 `METRIC_PILOT_PRODUCTION_DSN`。DSN 必须连接到已登记数据源的同一 host/port/database；写入账号需对源表 SELECT、目标 Schema CREATE，并能管理自己创建的专用目标表和授予原只读账号 SELECT。不要填写真实密码到任务表单。
5. 选择最多 366 天的半开日期区间并“申请运行”，批准本次操作后执行。查看步骤、质量对账、金额、运行 ID；失败后使用新请求键重新申请审批。
6. 首次成功的产物到“数据资产 → 待审核”核对字段并发布，随后可被已有只读查询和 RAG 使用。在指标中心审核执行契约时，可以显式绑定该汇总资产；不会自动改写现有指标。
7. 数据已提交但目录登记失败时，运行显示“待核对元数据”；管理员点击“恢复元数据登记”，不会再次写入业务数据。源数据与平台元数据库不是一个分布式事务，遇到进程被强制终止等无法记录的中断，需要管理员核对后处理，不能当作自动容灾方案。

## 主要文件

- `backend/data_services/metrics.py`：结构化指标解析、共享编译、只读执行、版本与审计。
- `backend/data_services/production.py`：登记任务、权限/字段复查、参数、运行视图。
- `backend/data_services/production_sql.py`：固定 SQL 模板与数据库事务/对账。
- `backend/data_services/production_runner.py`：审批绑定、幂等、记录、产物草稿、数据版本及实际血缘。
- `backend/api/data_services.py`：认证 HTTP 接口。
- `src/pages/catalog/{DataServicesPanel,ProductionPanel}.jsx`：前端入口。
- `scripts/verify_data_platform.py`、`scripts/verify_data_platform_ui.cjs`：可重复验收。
- `deploy/airflow/`：可选外部调度接入模板和配置说明。
